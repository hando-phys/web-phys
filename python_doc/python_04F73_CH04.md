# 4-1 結構化程式設計概念
## 程式的執行邏輯

---

# 4-1 什麼是結構化程式設計？
- 早期寫程式常使用 `goto` 指令跳來跳去，導致程式碼像義大利麵一樣混亂（Spaghetti code）。
- 為了讓程式易讀、好維護，學者提出了「結構化程式設計」。
- 規定所有程式都只能由**三種基本結構**組成。

---

# 4-1 程式的三大基本結構
1. **循序結構 (Sequential)**：
   - 程式碼由上往下，一行一行依序執行。
   - 這是所有程式最基礎的執行方式。
2. **選擇結構 (Selection)**：
   - 遇到分岔路口，根據「條件」決定要走哪一條路。
   - 例如：如果下雨就帶傘，否則就不帶傘。
3. **重複結構 (Iteration / Loop)**：
   - 條件成立時，重複執行某段程式碼。
   - 例如：罰寫 100 次。

---

# 4-1 選擇結構的重要性
- 讓程式具有「判斷能力」與「智慧」。
- 電腦不再只是死板地從頭執行到尾。
- 可以根據使用者的輸入或不同的狀況，給出不同的回應。
- 在 Python 中，我們使用 `if` 相關指令來實現選擇結構。

---

# 4-2 單向選擇結構
## 如果...就... (if)

---

# 4-2 單向選擇結構概念
- 只有一個條件測試。
- **當條件成立 (True) 時**：執行指定的程式區塊。
- **當條件不成立 (False) 時**：什麼都不做，直接跳過，繼續執行後面的程式。

---

# 4-2 單向選擇結構語法
- 使用 `if` 關鍵字。
- 條件後方必須加上冒號 `:`。
- 條件成立時要執行的程式碼，**必須縮排**（通常為 4 個空白）。

```python
if 條件判斷式:
    # 條件成立時要執行的程式碼
    # 必須縮排！
```

---

# 4-2 縮排的重要性 (複習)
- Python 靠「縮排」來辨識哪些程式碼屬於 `if` 的管轄範圍。
- 縮排結束，代表 `if` 區塊結束。

```python
weather = "下雨"

if weather == "下雨":
    print("帶傘出門")  # 屬於 if 區塊
    print("穿雨鞋")    # 屬於 if 區塊

print("出門去！")      # 不管有沒有下雨都會執行
```

---

# 4-2 單向選擇範例：及格通知
- **情境**：輸入學生成績，如果分數大於或等於 60 分，就印出「恭喜及格！」。

```python
score = int(input("請輸入成績："))

if score >= 60:
    print("恭喜及格！")
    print("可以得到小禮物一份。")

print("程式執行結束。")
```

---

# 4-2 單向選擇範例：滿額折扣
- **情境**：購物滿 1000 元，可享有 9 折優惠。

```python
total = int(input("請輸入購物總金額："))

# 如果滿 1000 元，重新計算總金額
if total >= 1000:
    print("符合滿千打九折優惠！")
    total = total * 0.9

print(f"您總共需要支付 {total} 元")
```

# 4-3 雙向選擇結構
## 如果...就...否則... (if-else)

---

# 4-3 雙向選擇結構概念
- 條件測試後，有兩條路可以走，**必定會執行其中一條**。
- **當條件成立 (True) 時**：執行第一區塊的程式碼。
- **當條件不成立 (False) 時**：執行第二區塊的程式碼。

---

# 4-3 雙向選擇結構語法
- 結合 `if` 與 `else` 關鍵字。
- `else` 後面也要加冒號 `:`。
- `else` 本身不需要條件（因為它包含了所有不符合 `if` 的情況）。

```python
if 條件判斷式:
    # 條件成立時執行的程式碼
else:
    # 條件不成立時執行的程式碼
```

---

# 4-3 雙向選擇範例：及格與不及格
- **情境**：輸入成績，及格印出「及格」，不及格印出「要補考」。

```python
score = int(input("請輸入成績："))

if score >= 60:
    print("恭喜及格！")
else:
    print("不及格，請準備補考。")
```

---

# 4-3 雙向選擇範例：奇數與偶數判斷
- **情境**：輸入一個整數，判斷它是奇數還是偶數。
- **技巧**：利用求餘數運算子 `%`。除以 2 餘數為 0 就是偶數。

```python
num = int(input("請輸入一個整數："))

if num % 2 == 0:
    print(f"{num} 是偶數")
else:
    print(f"{num} 是奇數")
```

---

# 4-3 雙向選擇範例：密碼驗證
- **情境**：模擬簡單的登入系統。

```python
password = input("請輸入密碼：")

if password == "python123":
    print("密碼正確，歡迎登入！")
else:
    print("密碼錯誤，請重新輸入。")
```

# 4-4 多向選擇結構
## 多種情況的判斷 (if-elif-else)

---

# 4-4 多向選擇結構概念
- 當情況超過兩種時使用（例如：成績分 A, B, C, D 等級）。
- 程式會由上往下依序檢查條件。
- **只要有一個條件成立**，執行完該區塊後，就會**直接跳出**整個選擇結構。
- 如果前面都不成立，最後會執行 `else` 區塊。

---

# 4-4 多向選擇結構語法
- 使用 `elif` (是 else if 的縮寫)。
- 可以有多個 `elif`。
- 最後的 `else` 是可省略的，但通常會保留用來處理「例外狀況」。

```python
if 條件1:
    # 條件1成立時執行
elif 條件2:
    # 條件1不成立，但條件2成立時執行
elif 條件3:
    # 條件1,2不成立，但條件3成立時執行
else:
    # 以上條件都不成立時執行
```

---

# 4-4 多向選擇範例：成績等第判斷
- 90分以上為 A，80-89分為 B，70-79分為 C，60-69分為 D，不及格為 F。

```python
score = int(input("請輸入成績："))

if score >= 90:
    print("等第：A")
elif score >= 80:
    print("等第：B")
elif score >= 70:
    print("等第：C")
elif score >= 60:
    print("等第：D")
else:
    print("等第：F")
```

---

# 4-4 邏輯順序的重要性
- 在多向選擇中，**條件的順序非常重要**！
- 錯誤示範：如果把 `>= 60` 放在最前面會發生什麼事？

```python
# 錯誤的邏輯順序
score = 95

if score >= 60:
    print("等第：D")  # 95大於60，印出D後就結束判斷了！
elif score >= 90:
    print("等第：A")  # 永遠執行不到這裡
```

---

# 4-4 多向選擇範例：BMI 體位判定
- 結合上一章的 BMI 計算，加入體位判斷。
- 體重過輕 (BMI < 18.5)
- 正常範圍 (18.5 <= BMI < 24)
- 異常過重 (BMI >= 24)

---

# 4-4 BMI 體位判定程式碼
```python
h = float(input("請輸入身高(公尺)："))
w = float(input("請輸入體重(公斤)："))
bmi = w / (h * h)

print(f"您的 BMI 為：{bmi:.1f}")

if bmi < 18.5:
    print("體重過輕，請多吃點！")
elif bmi < 24:
    print("體重正常，請繼續保持！")
else:
    print("體重過重，請注意飲食與運動！")
```

# 4-5 巢狀選擇結構
## 條件中的條件 (Nested if)

---

# 4-5 巢狀選擇結構概念
- 在一個 `if` 區塊裡面，又包含了另一個 `if` 判斷。
- 就像俄羅斯娃娃一樣，一層包著一層。
- 用於處理「前提條件成立後，還需要進一步細分」的複雜狀況。

---

# 4-5 巢狀選擇結構語法與縮排
- **縮排是關鍵！** 內層的 `if` 必須比外層的 `if` 多縮排一次（通常是 8 個空白）。

```python
if 外層條件:
    # 外層條件成立時執行
    if 內層條件:
        # 外層與內層條件都成立時執行
    else:
        # 外層成立，但內層不成立時執行
else:
    # 外層條件不成立時執行
```

---

# 4-5 巢狀選擇範例：遊樂園買票
- **情境**：
  - 身高未滿 120 公分：免費。
  - 身高 120 公分以上：
    - 學生：半票 (150元)
    - 非學生：全票 (300元)

---

# 4-5 遊樂園買票程式碼
```python
height = int(input("請輸入身高(公分)："))

if height < 120:
    print("免費入場！")
else:
    # 身高超過 120 公分，進一步判斷身分
    is_student = input("請問是學生嗎？(Y/N)：")

    if is_student == "Y" or is_student == "y":
        print("請購買半票 150 元")
    else:
        print("請購買全票 300 元")
```

# 4-5 巢狀選擇範例：閏年判斷
- **閏年規則**：
  1. 西元年份除以 4 不可整除，為平年。
  2. 西元年份除以 4 可整除，且除以 100 不可整除，為閏年。
  3. 西元年份除以 100 可整除，且除以 400 不可整除，為平年。
  4. 西元年份除以 400 可整除，為閏年。
- 簡單說：逢4一閏，逢100不閏，逢400又閏。

---

# 4-5 閏年判斷程式碼 (巢狀寫法)
```python
year = int(input("請輸入西元年份："))

if year % 4 == 0:
    if year % 100 == 0:
        if year % 400 == 0:
            print(f"{year} 是閏年")
        else:
            print(f"{year} 是平年")
    else:
        print(f"{year} 是閏年")
else:
    print(f"{year} 是平年")
```

---

# 4-5 閏年判斷程式碼 (邏輯運算子寫法)
- 巢狀結構如果太多層，會導致程式碼不易閱讀（稱為波動拳縮排）。
- 可以善用 `and` 與 `or` 邏輯運算子來簡化！

```python
year = int(input("請輸入西元年份："))

# 條件：(能被4整除 且 不能被100整除) 或 (能被400整除)
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(f"{year} 是閏年")
else:
    print(f"{year} 是平年")
```

# 總結與回顧
- **單向 (if)**：做與不做的抉擇。
- **雙向 (if-else)**：二選一的抉擇。
- **多向 (if-elif-else)**：多選一的抉擇，注意條件順序。
- **巢狀 (Nested if)**：條件內的條件，注意縮排層級。
