Chrome 安裝使用專屬的 Markdown 預覽外掛方法：

直接用 Chrome 看 Markdown 的原始碼很容易因為排版而難以閱讀。
使用專門的外掛不僅能解決亂碼，還能自動將 Markdown 渲染成漂亮的網頁排版。

  1. 在 Chrome 商店搜尋並安裝 Markdown Viewer 或 Markdown Reader。
  2. 同樣進入該外掛的管理頁面，勾選「允許存取檔案網址」。
  3. 之後直接把 .md 檔案拖入 Chrome，外掛就會自動以正確的 UTF-8 編碼並以美化後的 HTML 排版呈現。

安裝 Chrome 強制轉換編碼的外掛方法：

如果你經常需要直接在 Chrome 讀取各類純文字或網頁，建議安裝編碼切換擴充功能。

  1. 前往 Chrome 線上應用程式商店 搜尋並安裝 Charset 或 Set Character Encoding 擴充功能。
  2. 重要設定：安裝後，點擊 Chrome 右上角的「擴充功能圖示（拼圖形狀）」，進入該外掛的「管理擴充功能」。
  3. 務必勾選「允許存取檔案網址」（Allow access to file URLs），外掛才能對本地的 .md 檔案生效。
  4. 回到亂碼的 Markdown 網頁，點擊該外掛圖示（或點右鍵），將編碼手動切換為 Unicode (UTF-8) 即可。

Firefox 安裝使用專屬的 Markdown 預覽外掛方法：

  1. 在 Firefox 按F10，工具==>擴充套件與佈景主題==>看更多附加元件！ ==> Markdown Viewer 或 Markdown Reader。
  2. 特色：對擴充語法的支援度極高，除了基本的 Markdown，還完美支援 Emoji、數學公式、流程圖（Flowcharts）、甘特圖以及待辦事項勾選框（Checkboxes）。
  3. 適合對象：檔案包含大量圖表、科學公式或需要精美閱讀排版的使用者。
