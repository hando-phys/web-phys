# 2-1 Python 程式基礎架構
## 程式是怎麼組成的？

---

# 2-1 程式的執行順序
- **循序執行**：Python 程式碼預設是由上而下、一行一行執行的。
- 就像看書一樣，電腦會先讀完第一行，再讀第二行。
- 如果上面的程式碼有錯誤，程式就會停止，不會繼續往下執行。

---

# 2-1 程式的基本組成
- **模組 (Modules)**：引入其他人寫好的功能（例如數學模組）。
- **敘述 (Statements)**：程式執行的基本單位（例如指派變數、印出結果）。
- **運算式 (Expressions)**：由數值與運算符號組成，會產生一個結果（例如 `3 + 5`）。

---

# 2-1 引入模組 (Import)
- Python 有許多強大的「擴充包」，稱為模組或套件。
- 使用 `import` 關鍵字可以將這些功能加入我們的程式中。
- 範例：引入數學模組來計算平方根。

```python
import math

# 使用 math 模組裡的 sqrt 功能 (開根號)
result = math.sqrt(16)
print(result)  # 輸出：4.0
```

---

# 2-1 程式註解 (Comments)
- **什麼是註解？** 寫給「人」看的說明文字，電腦執行時會自動忽略。
- **為什麼要寫註解？**
  - 幫助自己記憶程式碼的功能。
  - 方便別人閱讀與理解你的程式。
  - 暫時停用某段程式碼（除錯時常用）。

---

# 2-1 單行註解與多行註解
- **單行註解**：使用井字號 `#`，後面的文字皆為註解。
- **多行註解**：使用三個單引號 `'''` 或三個雙引號 `"""` 包夾。

```python
# 這是一行單行註解，用來計算圓面積
r = 5
area = 3.14 * r * r  # 這也是註解，放在程式碼後方

"""
這是一段多行註解
可以用來寫比較長的說明
例如程式的作者、日期與詳細功能
"""
print(area)
```

# 2-2 Python 程式語法規則
## 寫 Python 必須遵守的規定

---

# 2-2 縮排 (Indentation)
- **這是 Python 最重要、最特別的規則！**
- 其他語言（如 C++）通常用大括號 `{}` 來區分程式區塊。
- Python 使用「空白縮排」來表示程式碼的階層關係。
- 建議：統一使用 **4 個半形空白鍵** 作為一次縮排（不要混用 Tab 鍵）。

---

# 2-2 縮排錯誤示範
- 如果縮排不正確，Python 會直接報錯 (IndentationError)，程式無法執行。

```python
# 錯誤示範：不該縮排的地方縮排了
print("Hello")
    print("World")  # 這裡會發生縮排錯誤

# 正確示範：
print("Hello")
print("World")
```

---

# 2-2 大小寫視為不同 (Case Sensitivity)
- 在 Python 中，英文的大寫和小寫代表完全不同的東西。
- 例如：`Apple`、`apple`、`APPLE` 是三個不同的變數。
- 內建指令也必須嚴格遵守大小寫，例如 `print` 不能寫成 `Print`。

---

# 2-2 變數命名規則
- 變數就像是裝資料的「箱子」，我們需要幫箱子取名字。
- **合法命名規則**：
  1. 只能包含英文字母、數字與底線 (`_`)。
  2. **不能以數字開頭**（例如 `1a` 是錯的，`a1` 是對的）。
  3. 不能使用 Python 的保留字（關鍵字）。

---

# 2-2 變數命名好習慣
- 盡量使用有意義的英文單字，讓程式碼「自我解釋」。
- **駝峰式命名**：`myStudentName` (單字字首大寫)
- **蛇形命名**：`my_student_name` (單字間用底線隔開，Python 最常用)
- 避免使用容易混淆的字母，如小寫 `l` (L) 與數字 `1`，大寫 `O` 與數字 `0`。

---

# 2-2 保留字 (Keywords)
- Python 系統已經預先定義好、有特殊功能的單字。
- **絕對不能**拿來當作變數名稱。
- 常見保留字：
  - `if`, `else`, `elif` (條件判斷)
  - `for`, `while` (迴圈)
  - `True`, `False` (布林值，注意首字母大寫)
  - `import`, `def`, `return`

---

# 2-2 程式碼換行
- 如果一行程式碼太長，可以使用反斜線 `\` 來換行，讓程式碼更容易閱讀。
- 在括號 `()`, `[]`, `{}` 內的程式碼，可以直接換行，不需要反斜線。

```python
# 使用反斜線換行
total = 100 + 200 + \
        300 + 400

# 在括號內直接換行 (推薦做法)
days = ["Monday", "Tuesday", "Wednesday",
        "Thursday", "Friday"]
```

# 2-3 Python 的輸入與輸出
## 讓程式與使用者互動

---

# 2-3 輸出：print() 函數
- 將資料顯示在螢幕上。
- 可以同時印出多個資料，中間用逗號 `,` 隔開。

```python
name = "小明"
age = 16

# 印出單一資料
print("歡迎來到 Python 課程！")

# 印出多個資料 (預設會用空白隔開)
print("我的名字是", name, "今年", age, "歲")
```

---

# 2-3 print() 的進階參數
- `sep` (Separator)：設定多個資料之間的分隔符號（預設是空白）。
- `end`：設定印完所有資料後要加什麼符號（預設是換行 `\n`）。

```python
# 更改分隔符號為星號
print("蘋果", "香蕉", "橘子", sep="***")
# 輸出：蘋果***香蕉***橘子

# 更改結尾符號，讓下一個 print 不換行
print("Hello", end=" ")
print("World")
# 輸出：Hello World
```

---

# 2-3 格式化輸出：f-string (推薦用法)
- 在字串前面加上小寫 `f` 或大寫 `F`。
- 把變數直接放在大括號 `{}` 裡面。
- 這是目前 Python 最直覺、最受歡迎的字串組合方式！

```python
name = "愛麗絲"
score = 95

# 傳統寫法 (容易漏掉逗號或加號)
print(name, "的成績是", score, "分")

# f-string 寫法 (直覺、易讀)
print(f"{name}的成績是{score}分")
```

---

# 2-3 輸入：input() 函數
- 讓程式暫停，等待使用者從鍵盤輸入資料。
- 括號內可以放入提示文字，告訴使用者該輸入什麼。
- **重要觀念**：`input()` 接收到的資料，型態永遠是「字串 (文字)」。

```python
# 取得使用者輸入
user_name = input("請輸入您的姓名：")

# 回應使用者
print(f"您好，{user_name}！很高興認識您。")
```

---

# 2-3 資料型態轉換
- 如果要將輸入的內容拿來做數學運算，必須先轉換型態。
- `int()`：轉換為整數 (Integer)。
- `float()`：轉換為浮點數 (小數, Float)。
- `str()`：轉換為字串 (String)。

```python
# 錯誤示範：文字相加
# age = input("請輸入年齡：")
# print(age + 1)  # 會發生錯誤！

# 正確示範：轉換為整數
age = int(input("請輸入年齡："))
print(f"明年您就 {age + 1} 歲了！")
```

---

# 2-3 經典範例：BMI 計算機
- 結合輸入、型態轉換、數學運算與格式化輸出。
- 公式：BMI = 體重(kg) / 身高(m)的平方

```python
# 1. 取得輸入並轉換型態
height_cm = float(input("請輸入身高(公分)："))
weight = float(input("請輸入體重(公斤)："))

# 2. 單位換算與計算
height_m = height_cm / 100
bmi = weight / (height_m * height_m)

# 3. 輸出結果 (取到小數點後兩位)
print(f"您的 BMI 值為：{bmi:.2f}")
```

---

# 2-3 經典範例：溫度轉換器
- 將攝氏溫度轉換為華氏溫度。
- 公式：華氏 = 攝氏 * 9/5 + 32

```python
# 取得攝氏溫度
celsius = float(input("請輸入攝氏溫度："))

# 計算華氏溫度
fahrenheit = celsius * 9 / 5 + 32

# 輸出結果
print(f"攝氏 {celsius} 度等於華氏 {fahrenheit} 度")
```
