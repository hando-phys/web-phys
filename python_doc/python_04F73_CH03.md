# 3-1 變數
## 程式中的記憶盒子

---

# 3-1-1 變數的運作原理
- **什麼是變數？**
  - 變數就像是一個「標籤」或「盒子」。
  - 用來在電腦記憶體中儲存資料，方便我們後續使用。
- **動態型別特性**：
  - Python 的變數不需要事先宣告資料型別。
  - 裝入什麼資料，它就會自動變成什麼型別。

---

# 3-1-1 變數的指派
- 使用等號 `=` 來將資料放入變數中。
- 讀法：將右邊的資料，指派給左邊的變數。

```python
# 將整數 100 放入名為 score 的變數中
score = 100

# 將字串 "小明" 放入名為 name 的變數中
name = "小明"
```

---

# 3-1-1 變數內容的改變
- 變數之所以叫「變」數，是因為裡面的內容可以隨時改變。
- 新的資料會覆蓋掉舊的資料。

```python
money = 50
print(money)  # 輸出：50

money = 100   # 重新指派新數值
print(money)  # 輸出：100
```

---

# 3-1-2 變數的命名規則
- 為了讓電腦看得懂，變數命名必須遵守嚴格的規定：
  1. 只能使用英文字母、數字與底線 (`_`)。
  2. **絕對不能以數字開頭**。
  3. 大小寫視為不同的變數（`Age` 和 `age` 是不一樣的）。

---

# 3-1-2 變數命名：合法與不合法
- **合法的變數名稱**：
  - `score`
  - `student_name`
  - `math_score_1`
- **不合法的變數名稱**：
  - `1_student` (不能以數字開頭)
  - `my-name` (不能使用連字號)
  - `my name` (不能有空白)

---

# 3-1-2 避開保留字 (Keywords)
- Python 系統已經使用的單字，不能拿來當變數名稱。
- 常見保留字：
  - `if`, `else`, `for`, `while`
  - `True`, `False`, `and`, `or`, `not`
  - `import`, `def`, `return`, `class`
- 如果不小心用到，程式會出現語法錯誤 (SyntaxError)。

---

# 3-2 資料型別
## 資料的種類

---

# 3-2 為什麼需要資料型別？
- 現實生活中，資料有不同的形式（文字、數字、小數）。
- 電腦需要知道資料的型別，才能決定如何處理它們。
- 例如：數字可以做加減乘除，文字則不行。

---

# 3-2 常見的基礎資料型別
- **整數 (int)**：沒有小數點的數字。
  - 範例：`10`, `-5`, `0`
- **浮點數 (float)**：帶有小數點的數字。
  - 範例：`3.14`, `-2.5`, `1.0`

---

# 3-2 常見的基礎資料型別 (續)
- **字串 (str)**：用引號包起來的文字。
  - 範例：`"Hello"`, `'Python'`, `"123"`
- **布林值 (bool)**：表示真或假，只有兩個值。
  - 範例：`True` (真), `False` (假)
  - 注意：字首必須大寫！

---

# 3-2 查詢資料型別：type()
- 如果不確定變數裡裝的是什麼型別，可以使用 `type()` 函數來查詢。

```python
a = 10
print(type(a))  # 輸出：<class 'int'>

b = 3.14
print(type(b))  # 輸出：<class 'float'>

c = "Hello"
print(type(c))  # 輸出：<class 'str'>
```

# 3-3 運算子
## 讓資料產生互動的符號

---

# 3-3 運算子是什麼？
- 運算子 (Operators) 是用來對變數或數值執行運算的特殊符號。
- 就像數學中的加減乘除符號一樣。
- Python 提供了多種運算子來處理不同的任務。

---

# 3-3-1 指定運算子
- 最基本的指定運算子就是等號 `=`。
- 作用：將右方的「值」或「運算結果」存入左方的「變數」。

```python
x = 10        # 將 10 指定給 x
y = x + 5     # 將 x+5 的結果 (15) 指定給 y
```

---

# 3-3-1 多重指定
- Python 允許一次為多個變數指定數值，讓程式碼更簡潔。

```python
# 同時指定多個變數為不同的值
a, b, c = 1, 2, 3

# 同時指定多個變數為相同的值
x = y = z = 100
```

---

# 3-3-2 算術運算子 (基本)
- 用來執行常見的數學運算：
  - `+`：加法
  - `-`：減法
  - `*`：乘法
  - `/`：除法 (結果永遠是浮點數 float)

---

# 3-3-2 算術運算子 (進階)
- Python 特有的實用數學運算子：
  - `//`：求商數 (無條件捨去小數點)
  - `%`：求餘數 (非常常用於判斷奇偶數或倍數)
  - `**`：指數 (次方)

---

# 3-3-2 算術運算子範例
```python
a = 10
b = 3

print(a / b)   # 輸出：3.3333333333333335 (除法)
print(a // b)  # 輸出：3 (求商)
print(a % b)   # 輸出：1 (求餘數，10除以3餘1)
print(a ** b)  # 輸出：1000 (10的3次方)
```

---

# 3-3-3 擴展型指定運算子
- 將「算術運算」與「指定運算」結合在一起的縮寫寫法。
- 可以讓程式碼更簡短。
- 常見符號：`+=`, `-=`, `*=`, `/=`, `%=`

---

# 3-3-3 擴展型指定運算子範例
```python
count = 5

# 傳統寫法：將 count 加 1 後再存回 count
count = count + 1

# 擴展型寫法：效果完全相同
count += 1

print(count)  # 輸出：7
```

---

# 3-3-4 比較運算子
- 用來比較兩個數值的大小或是否相等。
- 運算結果永遠是**布林值** (`True` 或 `False`)。
- 常見符號：
  - `==`：等於 (注意是兩個等號！)
  - `!=`：不等於

---

# 3-3-4 比較運算子 (大小比較)
- `>`：大於
- `<`：小於
- `>=`：大於或等於
- `<=`：小於或等於

---

# 3-3-4 比較運算子範例
```python
score = 85

print(score == 100)  # 輸出：False
print(score != 60)   # 輸出：True
print(score >= 80)   # 輸出：True
print(score < 90)    # 輸出：True
```

---

# 3-3-5 邏輯運算子
- 用來組合多個比較條件。
- 運算結果也是**布林值**。
- 包含三個關鍵字：`and`, `or`, `not`

---

# 3-3-5 邏輯運算子：and (且)
- 規則：所有條件都必須是 True，結果才是 True。
- 只要有一個 False，結果就是 False。

```python
# 判斷成績是否在 80 到 90 之間
score = 85
result = (score >= 80) and (score <= 90)
print(result)  # 輸出：True
```

---

# 3-3-5 邏輯運算子：or (或)
- 規則：只要有一個條件是 True，結果就是 True。
- 全部都是 False，結果才是 False。

```python
# 判斷是否為假日 (星期六或星期日)
day = "星期六"
is_holiday = (day == "星期六") or (day == "星期日")
print(is_holiday)  # 輸出：True
```

---

# 3-3-5 邏輯運算子：not (反相)
- 規則：將 True 變成 False，將 False 變成 True。

```python
is_raining = True
# 如果沒有下雨
print(not is_raining)  # 輸出：False
```

---

# 3-3-6 in 運算子
- 稱為「成員運算子」。
- 用來檢查某個值是否存在於一個序列（如字串、列表）中。
- 結果為布林值。

```python
text = "Hello Python"
print("Python" in text)  # 輸出：True
print("Java" in text)    # 輸出：False
```

---

# 3-3-6 is 運算子
- 稱為「身分運算子」。
- 用來檢查兩個變數是否指向記憶體中的「同一個物件」。
- 注意：`==` 是比較「值」是否相等，`is` 是比較「記憶體位置」是否相同。

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)  # True (內容相同)
print(a is b)  # False (記憶體位置不同)
print(a is c)  # True (指向同一個位置)
```

---

# 3-3-7 位元運算子 (進階概念)
- 將數字轉換為二進位 (0 和 1) 後，逐位元進行運算。
- 較常應用於底層系統開發或特殊演算法。
- 包含：
  - `&` (位元 AND)
  - `|` (位元 OR)
  - `^` (位元 XOR)
  - `~` (位元 NOT)

---

# 3-3-7 位元運算子：位移
- `<<`：向左位移 (相當於乘以 2 的 n 次方)
- `>>`：向右位移 (相當於除以 2 的 n 次方)

```python
x = 2      # 二進位：0010
y = x << 1 # 向左移1位：0100 (十進位的 4)
print(y)   # 輸出：4
```

---

# 3-3-8 運算子優先權次序
- 當一個程式碼中有多種運算子時，誰先執行？
- 就像數學的「先乘除後加減」。
- 如果不確定，**強烈建議使用小括號 `()`** 來明確指定順序！

---

# 3-3-8 常見優先權順序 (由高到低)
1. 括號 `()`
2. 指數 `**`
3. 乘除、求商、求餘 `*`, `/`, `//`, `%`
4. 加減 `+`, `-`
5. 比較運算子 `==`, `>`, `<` 等
6. 邏輯運算子 `not`, `and`, `or`
7. 指定運算子 `=`, `+=` 等

---

# 3-4 字串
## 文字的處理藝術

---

# 3-4 字串的宣告
- 可以使用單引號 `' '` 或雙引號 `" "` 來建立字串。
- 兩者效果相同，但必須成對使用。

```python
str1 = '這是單引號字串'
str2 = "這是雙引號字串"

# 如果字串內容包含單引號，外面就用雙引號包裝
msg = "I'm a student."
```

---

# 3-4 跳脫字元 (Escape Character)
- 使用反斜線 `\` 加上特定字母，用來表示無法直接輸入的特殊字元。
- 常見跳脫字元：
  - `\n`：換行 (New line)
  - `\t`：Tab 鍵 (縮排)
  - `\\`：印出一個反斜線
  - `\"`：印出一個雙引號

---

# 3-4-1 字串運算子：串接 (+)
- 加號 `+` 用在數字是數學相加。
- 加號 `+` 用在字串，則是將兩個字串「連接」在一起。

```python
first_name = "王"
last_name = "小明"
full_name = first_name + last_name
print(full_name)  # 輸出：王小明
```

---

# 3-4-1 字串運算子：重複 (*)
- 乘號 `*` 加上一個整數，可以讓字串重複指定的次數。

```python
cheer = "加油！"
print(cheer * 3)
# 輸出：加油！加油！加油！

# 常用於印出分隔線
print("-" * 20)
# 輸出：--------------------
```

---

# 3-4-1 字串運算子：索引 ([])
- 字串是由一連串字元組成的，每個字元都有一個「編號」(索引值)。
- **注意：Python 的索引值是從 0 開始算！**

```python
text = "Python"
# P  y  t  h  o  n
# 0  1  2  3  4  5

print(text[0])  # 輸出：P
print(text[3])  # 輸出：h
```

---

# 3-4-1 字串運算子：切片 ([:])
- 可以一次取出字串中的一小段。
- 語法：`[起始位置 : 結束位置]`
- **規則：包含起始位置，但不包含結束位置！**

```python
text = "Hello World"
print(text[0:5])  # 輸出：Hello (取索引 0,1,2,3,4)
print(text[6:])   # 輸出：World (從索引 6 取到最後)
```

# 3-5 範例 1：變數值交換
- **情境**：有兩杯飲料，A杯裝可樂，B杯裝雪碧，如何將兩杯飲料互換？
- **解法 1 (傳統)**：需要第三個空杯子 (暫存變數)。
- **解法 2 (Python 特有)**：直接交換！

---

# 3-5 範例 1 程式碼
```python
a = 10
b = 20
print(f"交換前：a={a}, b={b}")

# Python 特有的變數交換寫法
a, b = b, a

print(f"交換後：a={a}, b={b}")
```

---

# 3-5 範例 2：計算圓面積與周長
- **目標**：讓使用者輸入圓的半徑，程式計算並輸出面積與周長。
- **公式**：
  - 面積 = 半徑 * 半徑 * 3.14
  - 周長 = 半徑 * 2 * 3.14

---

# 3-5 範例 2 程式碼
```python
# 取得輸入並轉換為浮點數
r = float(input("請輸入圓的半徑："))
pi = 3.14159

# 計算
area = r ** 2 * pi
perimeter = r * 2 * pi

# 輸出結果 (取到小數點後兩位)
print(f"圓面積為：{area:.2f}")
print(f"圓周長為：{perimeter:.2f}")
```

---

# 3-5 範例 3：提取數字的各個位數
- **目標**：輸入一個三位數整數，分別印出它的百位、十位、個位數字。
- **技巧**：利用求商 `//` 與求餘數 `%` 運算子。

---

# 3-5 範例 3 程式碼
```python
num = int(input("請輸入一個三位數(100-999)："))

# 擷取各個位數
hundreds = num // 100          # 求百位數
tens = (num // 10) % 10        # 求十位數
ones = num % 10                # 求個位數

print(f"百位數：{hundreds}")
print(f"十位數：{tens}")
print(f"個位數：{ones}")
```
