# 5-1 迴圈的基本架構與概念
## 讓電腦幫你做重複的事

---

# 5-1 為什麼需要迴圈？
- 想像一下，如果要你在螢幕上印出 1 到 100 的數字，你會怎麼做？
- 寫 100 次 `print()` 嗎？太累了！
- **迴圈 (Loop)** 就是用來解決「重複性工作」的語法。
- 它可以讓一段程式碼執行指定的次數，或是直到某個條件不成立為止。

---

# 5-1 迴圈的兩大類型
在 Python 中，迴圈主要分為兩種：
1. **計數迴圈 (for 迴圈)**：
   - 已經知道要重複執行「幾次」。
   - 適合用來處理固定次數的任務，或走訪資料集合。
2. **條件迴圈 (while 迴圈)**：
   - 不確定要執行幾次，只知道「當某個條件成立時」就繼續做。
   - 適合用來處理需要等待特定狀況發生的任務。

---

# 5-2 計數迴圈結構 — 使用 for
## 掌握次數的控制

---

# 5-2 for 迴圈的基本語法
- 使用 `for` 與 `in` 關鍵字。
- 每次迴圈執行時，會從「序列」中取出一個元素，放入「變數」中。
- 迴圈內的程式碼**必須縮排**。

```python
for 變數 in 序列或範圍:
    # 每次迴圈要執行的程式碼
    # 必須縮排！
```

---

# 5-2 認識好幫手：range() 函數
- 要控制 `for` 迴圈的次數，最常搭配 `range()` 函數使用。
- `range()` 可以產生一連串的整數數列。
- **重要規則：包含起始值，但不包含結束值！**

---

# 5-2 range() 的三種用法
1. **range(結束值)**：
   - 從 0 開始，到結束值的前一個數字。
   - `range(5)` 會產生：0, 1, 2, 3, 4
2. **range(起始值, 結束值)**：
   - 從起始值開始，到結束值的前一個數字。
   - `range(1, 6)` 會產生：1, 2, 3, 4, 5
3. **range(起始值, 結束值, 遞增/減值)**：
   - 可以設定每次跳動的間距（步長）。
   - `range(1, 10, 2)` 會產生：1, 3, 5, 7, 9

---

# 5-2 for 迴圈範例：印出數字
- **目標**：印出 1 到 5 的數字。

```python
# i 是一個習慣用的計數變數名稱 (index/iterator)
for i in range(1, 6):
    print(i)

print("迴圈結束！")
```
- 執行結果會依序印出 1, 2, 3, 4, 5，然後印出「迴圈結束！」。

---

# 5-2 for 迴圈範例：印出偶數
- **目標**：印出 2 到 10 之間的所有偶數。
- **技巧**：利用 `range()` 的第三個參數（遞增值）。

```python
# 從 2 開始，到 11 之前結束，每次加 2
for num in range(2, 11, 2):
    print(num)
```
- 執行結果：2, 4, 6, 8, 10

---

# 5-2 for 迴圈範例：倒數計時
- **目標**：從 5 倒數到 1。
- **技巧**：將遞增值設為負數（遞減）。

```python
# 從 5 開始，到 0 之前結束，每次減 1
for i in range(5, 0, -1):
    print(i)

print("新年快樂！")
```

---

# 5-2 經典範例：計算 1 加到 100 的總和
- 這是程式設計中最經典的迴圈練習題！
- **演算法**：
  1. 準備一個變數 `total` 用來存總和，初始值為 0。
  2. 使用迴圈產生 1 到 100 的數字。
  3. 每次迴圈將產生的數字加到 `total` 中。

---

# 5-2 1 加到 100 程式碼
```python
total = 0  # 準備一個空箱子裝總和

# 產生 1 到 100 的數字
for i in range(1, 101):
    total = total + i  # 將 i 加進 total 中 (也可寫成 total += i)

# 迴圈結束後，印出最終結果
print(f"1 加到 100 的總和為：{total}")
```

---

# 5-2 for 迴圈走訪字串
- `for` 迴圈不僅能搭配 `range()`，還能直接把字串拆解，一個字一個字拿出來。

```python
text = "Python"

for char in text:
    print(char)
```
- 執行結果會分行印出 P, y, t, h, o, n。

# 5-3 條件迴圈結構 — 使用 while
## 只要條件成立，就繼續做

---

# 5-3 while 迴圈的基本語法
- 使用 `while` 關鍵字。
- 只要後面的「條件判斷式」結果為 `True`，就會一直執行迴圈內的程式碼。
- 條件不成立 (`False`) 時，迴圈才會結束。

```python
while 條件判斷式:
    # 條件成立時，重複執行的程式碼
    # 必須縮排！
```

---

# 5-3 while 迴圈的三大要素
要寫好一個 `while` 迴圈，通常需要具備三個條件，缺一不可：
1. **初始值**：在迴圈開始前，設定控制變數的初始狀態。
2. **條件判斷**：決定迴圈是否繼續執行的條件。
3. **變數更新**：在迴圈內部改變控制變數的值，讓條件有機會變成 `False`。

---

# 5-3 while 迴圈範例：印出數字
- **目標**：使用 `while` 印出 1 到 5 的數字。

```python
i = 1           # 1. 初始值

while i <= 5:   # 2. 條件判斷
    print(i)
    i = i + 1   # 3. 變數更新 (非常重要！)

print("迴圈結束！")
```

---

# 5-3 致命錯誤：無窮迴圈 (Infinite Loop)
- 如果忘記寫「變數更新」，或者條件永遠為 `True`，迴圈就會永遠執行下去，導致程式當機！
- **如何自救？** 在終端機或 IDLE 中，按下 `Ctrl + C` 可以強制中斷程式。

```python
# 錯誤示範：無窮迴圈
i = 1
while i <= 5:
    print(i)
    # 忘記寫 i = i + 1，i 永遠是 1，條件永遠成立！
```

---

# 5-3 經典範例：while 計算 1 加到 100
- 同樣的題目，用 `while` 怎麼寫？

```python
total = 0
i = 1            # 從 1 開始加

while i <= 100:  # 加到 100 為止
    total += i
    i += 1       # 記得要把 i 加 1，準備下一次迴圈

print(f"1 加到 100 的總和為：{total}")
```

---

# 5-3 什麼時候該用 while？
- 當你**不知道迴圈要執行幾次**的時候，`while` 是最好的選擇。
- 例如：要求使用者輸入正確密碼，只要輸入錯誤，就「一直」要求重新輸入。

---

# 5-3 經典範例：密碼驗證迴圈
- **情境**：密碼是 "1234"，使用者輸入錯誤就一直問，直到答對為止。

```python
password = ""  # 初始值設為空字串

# 只要密碼不是 "1234"，就繼續執行迴圈
while password != "1234":
    password = input("請輸入密碼：")

    if password != "1234":
        print("密碼錯誤，請再試一次！")

# 離開迴圈代表條件不成立 (密碼等於 "1234" 了)
print("密碼正確，歡迎登入！")
```

---

# 總結與比較
- **for 迴圈**：
  - 像是一個有明確起點和終點的跑道。
  - 適合已知次數、走訪數列 (`range`) 或字串。
- **while 迴圈**：
  - 像是一個看守員，只要條件符合就不放行。
  - 適合未知次數、等待特定條件發生的情況。
  - **務必注意避免無窮迴圈！**
