# 1-1 認識程式語言
## 進入程式設計的世界

---

# 1-1-1 何謂程式語言？
- **溝通的橋樑**：人類與電腦溝通的工具。
- 電腦的母語是「機器語言」（由 0 和 1 組成）。
- 程式語言讓我們用接近人類語言的方式下達指令。
- 透過「翻譯」，電腦就能理解並執行我們的工作。

---

# 1-1-1 為什麼要學程式語言？
- **自動化**：讓電腦幫我們處理重複性高的工作。
- **解決問題**：訓練邏輯思考與運算思維。
- **創造力**：開發遊戲、網站、應用程式。

---

# 1-1-2 程式語言的分類
- 依據「接近人類或電腦」的程度，可分為：
  1. **低階語言** (Low-level Language)
  2. **高階語言** (High-level Language)

---

# 1-1-2 低階語言
- **機器語言 (Machine Language)**：
  - 由 0 和 1 組成，電腦直接執行。
  - 人類極難閱讀與撰寫。
- **組合語言 (Assembly Language)**：
  - 用簡單的英文縮寫（助憶碼）代替 0 和 1。
  - 執行速度快，但仍不易學習。

---

# 1-1-2 高階語言
- 接近人類日常使用的語言（通常是英文）與數學公式。
- 易讀、易寫、易維護。
- 需要透過「編譯器」或「直譯器」翻譯給電腦聽。
- 範例：Python, Java, C++, JavaScript。

---

# 1-1-2 編譯與直譯的差異
- **編譯語言 (Compiled)**：
  - 像翻譯整本書，全部翻完才出版（執行）。
  - 執行速度快，如 C++。
- **直譯語言 (Interpreted)**：
  - 像同步口譯，講一句翻一句。
  - 跨平台方便，除錯容易，如 Python。

---

# 1-1-3 程式語言在生活上的應用
- **網頁開發**：你每天瀏覽的網站與社群媒體。
- **手機 App**：遊戲、通訊軟體、行動支付。
- **資料分析**：天氣預報、股市分析、推薦系統。
- **物聯網 (IoT)**：智慧家庭、自動駕駛。

---

# 1-1-3 程式語言對科技創新的影響
- **人工智慧 (AI)**：ChatGPT、影像辨識、語音助理。
- **醫療科技**：基因定序、AI 輔助診斷。
- **太空探索**：火箭軌道計算、火星探測車控制。
- 程式語言是推動現代科技進步的核心動力。

---

# 1-1-4 Python 程式語言
- 由荷蘭人 Guido van Rossum 於 1991 年發布。
- 命名由來：他喜歡的英國喜劇團體《Monty Python》。
- 標誌：兩條交纏的蟒蛇 (Python)。

---

# 1-1-4 Python 的特色
- **語法簡潔**：像閱讀英文一樣自然，適合初學者。
- **直譯式語言**：寫完立刻執行，方便測試。
- **跨平台**：Windows、Mac、Linux 都能跑。
- **強制縮排**：讓程式碼看起來整齊劃一。

---

# 1-1-4 為什麼選擇 Python？
- **豐富的標準函式庫**：內建許多實用工具（電池內建）。
- **強大的第三方套件**：AI、數據分析、爬蟲應有盡有。
- **社群龐大**：遇到問題在網路上很容易找到解答。
- 目前全球最受歡迎的程式語言之一！

# 1-2 程式設計演算法的介紹
## 解決問題的步驟

---

# 1-2 何謂演算法 (Algorithm)？
- **定義**：解決特定問題的一系列明確步驟。
- 就像是「食譜」：
  - 準備食材（輸入資料）
  - 按照步驟烹調（處理過程）
  - 完成料理（輸出結果）

---

# 1-2 演算法的特性
- **輸入 (Input)**：0 個或多個輸入資料。
- **輸出 (Output)**：至少產生 1 個結果。
- **明確性 (Definiteness)**：每個步驟都必須清楚無誤。
- **有限性 (Finiteness)**：步驟必須在有限次數內結束。
- **有效性 (Effectiveness)**：每個步驟都是可執行的。

---

# 1-2 生活中的演算法範例
- **問題**：如何泡一杯泡麵？
- **步驟**：
  1. 打開包裝。
  2. 取出調味料包並撕開倒入。
  3. 煮沸熱水。
  4. 將熱水倒入碗中至八分滿。
  5. 蓋上蓋子等待 3 分鐘。
  6. 打開蓋子，攪拌均勻，完成！

---

# 1-2 演算法的表達方式
- **自然語言**：用日常文字描述（如上一頁）。
- **虛擬碼 (Pseudocode)**：介於自然語言與程式碼之間。
- **流程圖 (Flowchart)**：用圖形符號表示步驟與邏輯。
- **程式碼**：最終交給電腦執行的實際語言。

---

# 1-2 流程圖基本符號
- **橢圓形**：開始 / 結束
- **平行四邊形**：輸入 / 輸出
- **矩形**：處理 / 運算
- **菱形**：判斷 / 條件分支
- **箭頭**：流程方向

## 準備你的程式設計工具

# 1-3 開發環境是什麼？
- 寫程式就像寫文章，需要「紙和筆」。
- 開發環境就是我們寫程式、測試、除錯的軟體工具。

# 1-3-1 Python 下載與安裝
- 請至 Python 官方網站：https://www.python.org/
- 點擊 "Downloads"，選擇適合的作業系統 (Windows/macOS)。
- 建議下載最新穩定版本 (Python 3.x)。

---

# 1-3-1 安裝時的重要步驟 (Windows)
- 執行安裝檔時，**務必勾選**：
  - `Add Python 3.x to PATH` (將 Python 加入環境變數)
- 勾選後點擊 `Install Now`。
- 這樣才能在電腦的任何地方呼叫 Python！

---

# 1-3-2 使用 Python 直譯器執行程式
- 打開「命令提示字元 (cmd)」或「終端機 (Terminal)」。
- 輸入 `python` 並按 Enter。
- 出現 `>>>` 符號，代表進入了 Python 互動模式 (REPL)。

---

# 1-3-2 互動模式 (REPL)
- **R**ead (讀取)：讀取你輸入的程式碼。
- **E**valuate (評估)：執行程式碼。
- **P**rint (輸出)：顯示執行結果。
- **L**oop (迴圈)：等待下一次輸入。
- 適合用來做簡單的計算或測試語法。

---

# 1-3-2 互動模式範例
- 在 `>>>` 後面輸入：
  `print("Hello, World!")`
- 按下 Enter，螢幕會顯示：
  `Hello, World!`
- 輸入 `exit()` 或按 `Ctrl+Z` 可離開互動模式。

---

# 1-3-3 使用官方 IDLE 編輯與執行程式
- **IDLE** 是 Python 內建的整合開發環境。
- 包含兩個主要視窗：
  1. **Shell 視窗**：類似互動模式，可即時看結果。
  2. **Editor 視窗**：用來撰寫並儲存完整的程式碼檔案。

---

# 1-3-3 在 IDLE 中建立新檔案
1. 打開 IDLE (Python GUI)。
2. 點擊左上角 `File` -> `New File`。
3. 開啟了一個空白的編輯器視窗。
4. 在這裡可以寫下多行程式碼。

---

# 1-3-3 儲存與執行程式
1. 寫完程式後，點擊 `File` -> `Save`。
2. 將檔案命名為 `hello.py` (副檔名必須是 .py)。
3. 點擊上方選單 `Run` -> `Run Module` (或按快捷鍵 `F5`)。
4. 執行結果會顯示在 Shell 視窗中。

# 1-3-5 簡單加法計算機範例
- **目標**：讓使用者輸入兩個數字，程式計算總和並顯示。
- **演算法**：
  1. 提示使用者輸入第一個數字。
  2. 提示使用者輸入第二個數字。
  3. 將兩個數字相加。
  4. 輸出結果。

---

# 1-3-5 認識 input() 與 print()
- `print()`：將資料輸出到螢幕上。
- `input()`：接收使用者從鍵盤輸入的資料。
- **注意**：`input()` 接收到的資料預設為「字串 (文字)」。

---

# 1-3-5 資料型態轉換
- 因為 `input()` 取得的是文字，不能直接做數學加法。
- 例如："5" + "3" 會變成 "53"。
- 必須使用 `int()` 將文字轉換為「整數 (Integer)」。
- 轉換後：5 + 3 才會等於 8。

---

# 1-3-5 加法計算機程式碼
```python
# 取得使用者輸入並轉換為整數
num1 = int(input("請輸入第一個數字: "))
num2 = int(input("請輸入第二個數字: "))

# 計算總和
total = num1 + num2

# 顯示結果
print("兩個數字的總和是:", total)
```

---

# 1-3-5 執行結果測試
- 畫面顯示：`請輸入第一個數字: `
- 使用者輸入：`15`
- 畫面顯示：`請輸入第二個數字: `
- 使用者輸入：`20`
- 畫面顯示：`兩個數字的總和是: 35`

# 1-4 物件導向程式設計的重要概念
## Object-Oriented Programming (OOP)

---

# 1-4 什麼是物件導向？
- 一種程式設計的「思維方式」。
- 將真實世界的事物抽象化為程式中的「物件 (Object)」。
- 讓程式碼更容易管理、重複使用與擴充。
- Python 是一種支援物件導向的語言。

---

# 1-4 類別 (Class) 與 物件 (Object)
- **類別 (Class)**：
  - 像是「設計圖」或「餅乾模具」。
  - 定義了事物的共同特徵與行為。
- **物件 (Object)**：
  - 根據設計圖做出來的「實體」或「烤出來的餅乾」。
  - 每個物件都有自己的狀態。

---

# 1-4 屬性 (Attribute) 與 方法 (Method)
- **屬性 (Attribute)**：
  - 物件的「特徵」或「狀態」（名詞/形容詞）。
  - 例如：狗的顏色、品種、名字。
- **方法 (Method)**：
  - 物件能做的「動作」或「行為」（動詞）。
  - 例如：狗會吠叫、搖尾巴、跑步。

---

# 1-4 物件導向範例 (概念)
```python
# 定義一個「狗」的類別 (設計圖)
class Dog:
    # 屬性
    def __init__(self, name, color):
        self.name = name
        self.color = color

    # 方法
    def bark(self):
        print(self.name + " 說：汪汪！")

# 建立物件 (實體)
my_dog = Dog("小白", "白色")
my_dog.bark()  # 輸出：小白 說：汪汪！
```

---

# 1-4 物件導向的三大特性 (簡介)
1. **封裝 (Encapsulation)**：
   - 將資料和方法包裝在一起，隱藏內部細節，只提供操作介面（像遙控器）。
2. **繼承 (Inheritance)**：
   - 子類別可以接收父類別的特徵，減少重複寫程式碼（如：貓和狗都繼承「動物」）。
3. **多型 (Polymorphism)**：
   - 同樣的指令，不同的物件會有不同的反應（如：對貓和狗下達「叫」的指令，聲音不同）。
